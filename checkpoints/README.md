# 已训练模型

`best_resnet18.pth` 是当前页面可直接加载的 ResNet-18 六分类权重。它随代码提交，组员安装依赖后即可演示。

- 文件大小：44,792,971 字节。
- SHA-256：`e48318eea31a71d2ac795d6b408cf41b853b1c5bc1f4d713f661bd43de6e78db`。
- 权重字段：`model_state`。
- 类别字段：`classes`，按 `cardboard, glass, metal, paper, plastic, trash` 排列。
- 输入：RGB 图片，224×224，使用与 `app.py` 相同的 ImageNet 标准化参数。
- 输出：六个类别分数，页面使用 Softmax 转换为概率后显示 Top-3。

模型结构由 `model.py` 定义。训练方式以 `train.py` 为准；脚本默认加载 ImageNet 预训练参数、冻结主干、训练分类层 5 轮，按验证准确率保存最佳权重。当前权重仅保存参数和类别映射，课程报告中的轮次与指标应以实际训练记录为依据。

重新训练会更新此文件。仅在需要共享新的可用模型时提交权重更新，避免提交每个批次或每一轮的中间文件。
