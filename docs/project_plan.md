# 实施计划与交付清单

| 阶段 | 工作 | 交付 |
| --- | --- | --- |
| 第 1 周 | 获取并检查 TrashNet、固定划分、查看类别不平衡 | 数据清单、样本分布图 |
| 第 2 周 | 跑通 B 冻结训练，再完成 C 部分微调 | 真实最佳模型、日志和曲线 |
| 第 3 周 | 完成 A/B/C 同条件实验、误分类分析、联调界面 | 实验对比表、混淆矩阵、识别系统 |
| 第 4 周 | 测试真实环境图片、错误输入与不确定预测 | 报告、PPT、演示视频、复现说明 |

三人可按算法与数据、界面与推理、实验与报告分工；两人可合并算法与实验，另一人负责系统与报告。
